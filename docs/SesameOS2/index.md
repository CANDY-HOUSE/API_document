SesameSDK 是一個用於 iOS/Android 的簡單、功能強大且免費的 藍牙/IoT(物聯網) 庫。 官方Sesame app應用程序也是建構於此SesameSDK。SesameSDK 賦能您的app應用程序 **所有** Sesame app應用程序的功能:

- 註冊 Sesame系列設備(Sesame3, WiFi Module, Sesame bot, Sesame bike,...)
- 開關鎖
- 共享鑰匙
- 讀取歷史
- 升級SesameOS
- 各種設置
- 讀取電池電量
- iOS / iPadOS Widget
- Apple Watch應用程序

此 SesameSDK 目前僅支持 Sesame 3以上系列。 如果未來 Sesame1系列設備被升級成SesameOS2後，也能被支持。
